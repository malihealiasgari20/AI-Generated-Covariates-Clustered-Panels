# Analyses after the frozen study

This folder holds the analyses reported in Section 5.5 and Supplementary Section S8 of the article, with Supplementary Tables S13–S19. They were specified after the FINAL_V1 results were known, following the authors' internal review of 10 November 2026. They are post-hoc analyses, reported separately from the frozen study, and they change no FINAL_V1 hypothesis classification.

The analyses were fixed in a written plan before any production run:
- **Plan:** `R1_ANALYSIS_PLAN.md`.
- **Seal:** `R1_PLAN_SEAL.txt` holds the SHA-256 of the plan and of the run code (`r1_core.py`, `r1_run.py`, `test_r1_core.py`, `verify_reviewer.py`). It was written at 18:55 UTC on 13 November 2026, before the first production replication. To verify it, run `tail -n +2 R1_PLAN_SEAL.txt | sha256sum -c` in this folder.
- **Not sealed:** the summary script `r1_analyze.py` and the check `check_ps_floor.py`. The first computes the quantities that the plan lists; the second was added after the runs (see below).

"R1" is the internal label of these analyses. `verify_reviewer.py` reproduces two diagnostics from the internal review on panels of the frozen study: the variance check on E-4 and the independent-shock check on Experiment 3. These file names are kept because the seal covers the files.

## Contents

| Path | What it is |
|---|---|
| `code/r1_core.py` | The procedures and computations: linearized variances (ratio and calibration terms), the pairs cluster bootstrap, the independent-shock arms, predict-then-debias (PTD), design-weighted tuned PPI++ (E-10w), proxy strata and small-cluster intervals. It uses the FINAL_V1 code read-only. |
| `code/r1_run.py` | Runs the six modules (A1, A2, B, C, D1, D2) and writes one `.npz` per cell. |
| `code/r1_analyze.py` | Builds the summary tables in `analysis/`, with Monte Carlo standard errors. |
| `code/test_r1_core.py` | Mechanical tests on throwaway seeds. They reproduce the FINAL_V1 estimates and CR1 standard errors to 1e-9 and check the analytic calibration derivative against finite differences. |
| `code/verify_reviewer.py`, `verification/verify_reviewer_output.txt` | The two preliminary diagnostics. |
| `code/check_ps_floor.py`, `analysis/A1_ps_tds_floor_check.json` | A check added after the runs; details below. |
| `analysis/` | Every summary table used in the article: A1 and A2 (variance), B (independent-shock control), C (comparators), D1 (proxy strata), D2 (sparse validation). |
| `out/*/cells.json`, `out/run_log.txt` | Cell lists and the run log. |
| `run_all.sh` | Runs the modules in the order used. |
| `MANIFEST_SHA256.txt` | SHA-256 of every other file in this folder. |

**The PS-TDS-I floor check.** Module A1 computes PS-I, which is PS-TDS-I without its stabilization floor. The check compares the two replication by replication on the frozen-study panels:
- The floor bound in 4 of the 120,000 primary-grid replications and in none of the Experiment-2 replications.
- In those 4 replications, the coverage and rejection decisions of the CR1 intervals are the same.
- In all other replications, the two procedures agree to within 1e-15.

The per-replication `.npz` outputs (about 72 MB) are not stored here. They are regenerated exactly from the code and seeds:
- Configurations of the frozen study use the FINAL_V1 production panel and fold seeds.
- New draws use the `R1` seed namespace in `r1_core.r1_rng`.

The full run takes about one hour on two cores.

## Running

1. Unzip `ASMBI_Public_Archive.zip` at the repository root and place its `final_study_v1/` folder at `/mnt/user-data/outputs/Final_Study_v1`. Alternatively, set `FV1_CODE` to its `code/` folder; `verify_reviewer.py` always expects the first location.
2. Run:

```
cd post_frozen_analyses/code
python3 -I -B test_r1_core.py
bash ../run_all.sh
python3 -I -B r1_analyze.py
```

3. `check_ps_floor.py` also needs the FINAL_V1 per-replication checkpoints. They are regenerated by the FINAL_V1 runner. Set `FV1_RAW` to their folder, then run `python3 -I -B check_ps_floor.py`.

The software is the same as for FINAL_V1: Python 3.13.16, NumPy 2.5.3 and SciPy 1.18.1.
